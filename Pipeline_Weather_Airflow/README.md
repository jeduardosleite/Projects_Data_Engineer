# Pipeline Meteorológico com Apache Airflow

Este projeto é uma continuação do `Pipeline_Weather`, disponível neste
mesmo repositório.

[Consultar a primeira etapa do projeto](../Pipeline_Weather)

Na primeira etapa, foi desenvolvido o pipeline ETL responsável pela
extração, transformação e carga dos dados meteorológicos.

Nesta etapa, o Apache Airflow foi incorporado para realizar a
orquestração, o agendamento, o monitoramento e o controle das etapas
Extract, Transform e Load.
